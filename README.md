# 🎯 Item-to-Item Recommendation Engine Demo

A clean, interactive example of **Item-based Collaborative Filtering** using Python, SQL, and Streamlit.

## Features
- Item-to-item recommendations with cosine similarity
- SQLite backend
- Streamlit dashboard with interactive plots
- 500+ rows of synthetic user-item interactions

## Tech Stack
- Python (pandas, scikit-learn)
- SQLite
- Streamlit
- Plotly
